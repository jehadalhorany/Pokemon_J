# Pokémon J v04 — تحديث أول مشكلتين

هذه حزمة تحديث للنسخة الموجودة عندك، وليست تثبيتًا جديدًا. لا تحذف ملفات قديمة أو مجلد data أو public/assets/imported.

## التركيب

1. أوقف السيرفر بـ Ctrl+C.
2. فك ضغط Pokemon_J_v04_first_two_update.zip مباشرة داخل:

   `C:\Users\User\Documents\GitHub\Pokemon_J`

   وافق على استبدال الملفات. يجب أن ترى مجلد tools بجانب public وserver وpackage.json، وليس داخل مجلد إضافي.
3. افتح PowerShell داخل مجلد Pokemon_J وشغّل:

   ```powershell
   node tools/install-first-two-v04.mjs
   ```

   هذه الخطوة تربط السيرفر الحالي بالمشهد الأصلي، وتحفظ نسخة من server/index.mjs قبل تعديله. لا تستبدل بقية كود السيرفر ولا تمس الحفظ. إذا ظهرت رسالة Unsupported أو Unknown، لا تكمل وأرسل نصها.
4. بعد ظهور رسالة نجاح التركيب شغّل:

   ```powershell
   npm start
   ```

5. افتح http://localhost:3000 وحدّث الصفحة بـ Ctrl+F5.

هذا الملف للتعليمات فقط؛ لا تنقل محتوياته إلى الكود.

## ما تم التحقق منه

- واجهة Battle/NormalBattle_Bg الأصلية، مشهد skyland وكاميرا المعركة الأصلية مع تصحيح تحويل اتجاهها.
- الضغط الفعلي على الهجوم، قائمة الكرات، استخدام كرة، والانسحاب؛ استهلاك PP والكرة متصل بالسيرفر.
- ظهور أسماء Viridian Poké centre وViridian Poké mart وTrainers' school من سجلات المناطق الأصلية، مع إبقاء طبقة الأسماء مستقلة عن القوائم.
- دخول مركز العلاج بزر Enter والرجوع للمنطقة الأصلية.
- فحص بيانات أسماء 521 مدخلًا خارجيًا؛ جميعها تملك اسمًا من السجلات الأصلية. هذا فحص بيانات وليس تجربة فعلية لكل المباني.
- 80 اختبارًا برمجيًا ناجحًا. تحقق المتصفح في SOURCE_FIRST_TWO_VALIDATION.json.
- إصلاح بيانات مشهد المعركة في حفظ قديم فقط عندما يثبت تطابقه الوحيد مع سجل أصلي؛ لا يتم مسح المعركة أو الفريق أو الصحة أو PP أو المخزون.

## حدود هذه الدفعة

هذه الدفعة تعالج العرض والربط المذكورين. حسابات الضرر ونتيجة الالتقاط الحالية ما زالت من خدمة القتال المحلية، وليست نسخة مستعادة من السيرفر الأصلي. مؤثرات مهارات القتال ورمي الكرة والاهتزازات الأصلية ليست مكتملة. Great Ball معطلة في الواجهة لأن خدمة القتال الحالية لا تدعمها. لا تدّعي هذه الحزمة اكتمال نظام المعركة الأصلي.

تم تصدير 25 مشهدًا أصليًا؛ التجربة الفعلية شملت skyland فقط. skylandDodge لا يحتوي مجسمًا قابلًا للتصدير في المسار المستعاد، ولا يتم تعويضه بمشهد مخترع. لم نعدّل باقي المشاكل الخمس أو أرضيات العالم أو نماذج اللاعب في هذه الدفعة. يلزم بقاء حزم النماذج الأصلية الاثنتي عشرة الموجودة عندك.
