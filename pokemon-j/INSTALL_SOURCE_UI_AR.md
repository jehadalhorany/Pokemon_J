# Pokémon J v04 — تحديث الخريطة والمهمات والواجهة

هذه حزمة تعديلات فوق ملفات v04 الموجودة. لا تحتوي ملفات حفظ ولا تستبدل مجلد بيانات الحساب.

## التركيب

1. أوقف السيرفر من نافذة التشغيل باستخدام Ctrl+C.
2. احتفظ بنسخة من مجلد المشروع قبل الاستبدال.
3. فك Pokemon_J_v04_source_ui_patch.zip داخل هذا المجلد:

   C:\Users\User\Documents\GitHub\Pokemon_J

   المجلد المطلوب هو الذي يحتوي مباشرة على public وserver وpackage.json.
   اختر استبدال الملفات عند الطلب. لا تنشئ مجلد pokemon-j إضافيًا داخل المشروع.
4. شغّل السيرفر بنفس طريقتك السابقة. إذا كنت تستخدم npm، افتح الطرفية في مجلد المشروع واكتب npm start.
5. افتح رابط اللعبة واضغط Ctrl+F5.

لا تحذف مجلد data أو ملفات الحفظ أو public/assets/imported.
لا تحتاج رفع ملفات GitHub أو Render لتجربة التعديل محليًا.

## ما الذي يتغير

- الكاميرا تستخدم إعداد MapArea.Camera من ملفات الكاميرا الأصلية.
- واجهة Main/Main_Bg الأصلية تعرض الحساب والميني ماب والمهمة الحالية.
- الضغط على الميني ماب يفتح ShowMap_Window الأصلية مع رسم العالم و204 علامة مناطق.
- أسماء المدن والمباني وموقع اللاعب تأتي من MapMini وMapArea.
- نافذة المهمات تستخدم TaskCenter_Window الأصلية، مع بيانات الفصل الحالي وأيقونات المكافآت وأعدادها.
- زر Go يبدأ مسار المشي الحالي إلى هدف المهمة. اختُبر بدء مسار درج البيت للوصول للأم، وليس إكمال كل المهمات.
- زر Inspect Poké Ball السفلي القديم أزيل. يبقى التفاعل بالضغط على العنصر القريب أو Enter.

## حدود هذه الدفعة

هذه ليست نهاية تحويل اللعبة إلى الواجهات الأصلية.
- ربط أزرار القائمة وواجهة البوكيدكس وواجهة المعركة الأصلية لم يكتمل. أزرار القائمة الأصلية غير المربوطة لا تنفذ إجراءات.
- تبويبات Side وDaily وBounty ظاهرة من القالب الأصلي، لكن تشغيلها لم يكتمل. المتاح في هذه الدفعة المهمة الرئيسية.
- نافذة حوار الشخصيات وتفاصيل الشريك ما زالت تحتاج استبدالًا.
- السباحة والقفز وجميع الأبواب والسفر إلى جميع المناطق لم تُختبر بالكامل في هذه الدفعة.
- تحذير Unauthorized الأول عند إنشاء جلسة جديدة يتبعه إنشاء الحساب تلقائيًا، ولا يعني فقدان ملفات الحفظ.

## الفحص المنجز

- 45 اختبار سيرفر ناجحًا.
- فحص متصفح داخل اللعبة للخريطة، 204 علامات، الرجوع وEscape ومنع الحركة عند فتحها.
- فحص ظهور واجهة Main الأصلية وفتح نافذة المهمة الحالية ومكافآتها.
- الضغط على Go أغلق النافذة وبدأ مسارًا من 13 نقطة نحو درج البيت.
- لا أخطاء JavaScript في فحص الربط الأخير، ولا إحداثيات رسم NaN بعد تصحيح محرّك الإطارات.

## الملفات ومواقعها

public/scene.js — ربط العالم بالكاميرا والخريطة والمهمات.
public/source-camera.js — إعدادات الكاميرات الأصلية.
public/source-map.js — الخريطة ومحرك النوافذ المشترك.
public/source-hud.js — إطار الحساب والميني ماب والمهمة الحالية.
public/source-quests.js — نافذة المهمات.
public/native-package-loader.js — قراءة حزم الواجهات وصورها.
public/vendor/fairygui.module.js — محرّك العرض مع تصحيحات التوافق.
public/assets/original/packages — حزم وصور الواجهات المستخرجة من ملفاتك.
public/data/original — إعدادات الواجهات والكاميرات والخرائط من الداتا.

الحزمة تتضمن أيضًا اعتماديات التحديث السابق حتى لا تحتاج جمع ملفاتها يدويًا.
