# Pokémon J v04 — تحديث الواجهة والحوار والمسارات الأصلية

تحديث جزئي تراكمي، وليس اللعبة الأصلية كاملة. يشمل واجهة Main والخريطة ونافذة المهمة الرئيسية، حوار الأم والبروفيسور من نافذة Dialogue الأصلية، والمشي لكرات البداية وفق مسافة التفاعل في التكوين الأصلي. يعتمد اختيار الجيل والشريك على بيانات الأجيال الأصلية، مع تأكيد صريح قبل منح الشريك.

يلزم وجود حزم النماذج المحوّلة السابقة داخل public/assets/imported (models وtextures وanimations). لا تحذف هذا المجلد. الحزمة الجديدة تتضمن كتالوج النماذج وملفات الواجهة وبياناتها، ولا تعيد تنزيل النماذج الكبيرة.

التركيب:
1. أوقف السيرفر بـ Ctrl+C، وخذ نسخة احتياطية من مجلد المشروع.
2. نزّل الأجزاء الأحد عشر المرقمة Pokemon_J_v04_source_update من 01 إلى 11، ولا تركّب جزءًا وحده.
3. فك ضغط كل الأجزاء داخل المسار نفسه: `C:\Users\User\Documents\GitHub\Pokemon_J`، حيث يوجد package.json ومجلدا public وserver. هذه ملفات ZIP مستقلة؛ فك كل واحد في المكان نفسه، وليس داخل مجلد جديد لكل جزء.
4. وافق على استبدال الملفات. لا تمسح مجلد data أو ملفات الحفظ أو public/assets/imported. لا يوجد حذف تلقائي في التحديث.
5. شغّل السيرفر بالطريقة المعتادة، وحدّث المتصفح بـ Ctrl+F5.

التحقق: 51 فحص Node ناجح. نجح فحص المتصفح لمسار الطابق العلوي، السلالم، الأم، باب البيت، الطريق، باب المختبر، البروفيسور وكرات البداية. المعاينة لم تمنح شريكًا. نجح فحص حدود نص الحوار وتغيير الحجم وEnter، وكذلك الخريطة ذات 204 علامات والرجوع وEscape وزر Go. هذه فحوص محددة وليست فحصًا شاملًا لكل المناطق.

ما زال غير مكتمل: تحويل البوكيدكس والتفاصيل إلى الواجهة الأصلية، واجهة المعارك وقواعد الضربات الأصلية، بقية القوائم وأصناف المهمات، اللعب الجماعي والجايلد والاشتراكات. توجد أجزاء قديمة في هذه الأنظمة؛ لا يُقدّم هذا التحديث على أنه أزال كل الكود التجريبي. الأزرار الأصلية غير المربوطة تبقى معطلة.
